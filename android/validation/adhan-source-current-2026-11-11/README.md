# Asal pasangan adzan aktif — 11 November 2026

Pasangan aktif tetap pilihan pengguna: `Adzan-Misyari-Rasyid.mp3` untuk empat
waktu selain Subuh, dan `fajr_128_44.mp3` untuk Subuh. Bukti Makkah27Oktober
adalah sejarah pilihan terdahulu, bukan pasangan aktif saat ini.

[Hasil exact-hash](file-match.json) mencocokkan ulang kedua unduhan dari
[halaman penerbit](https://islamdownload.net/123801-download-suara-adzan.html)
dengan file pengguna: masing-masing3.713.152 dan2.996.349byte. Byte MP3 tetap
privat; tidak dimasukkan Git atau diganti. URL sumber dan hash bukan izin
redistribusi dan bukan verifikasi identitas pemilik rekaman.

Halaman menawarkan unduhan gratis dan melabeli rekaman Misyari/Subuh. Penelaahan
halaman ini belum menetapkan lisensi penyertaan rekaman ke aplikasi yang
didistribusikan, termasuk ketentuan penggunaan/atribusi. Tidak menyimpulkan
pemakaian dilarang; bukti izinnya belum terpenuhi. Tidak menghubungi penerbit
atau mengirim email. D02/D02a dan gerbang audio publik tetap terbuka untuk izin
serta penelaahan lafaz penuh. Durasi/pemutaran utuh pasangan sekarang memakai
[bukti HP10November](../phone-closeout-2026-11-10/README.md), tidak diulang atau
disamakan dengan pemeriksaan editorial seluruh lafaz.
