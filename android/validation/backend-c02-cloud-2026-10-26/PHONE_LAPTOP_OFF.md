# C02 — uji HP saat laptop mati

**Belum dijalankan.** Uji ini memerlukan tindakan pengguna pada HP dan laptop;
monitor GitHub atau preview cloud tidak menggantikannya.

1. Pakai Zikra pada HP dengan koneksi internet sendiri, melalui Wi-Fi router atau
   data seluler. Jangan memakai hotspot dari laptop yang akan dimatikan.
   APK terbaru lokal: `Zikra-AI-v1.9.7-beta-debug.apk`, 37.218.400 byte/code34.
   Bila memperbarui, pasang sebagai pembaruan tanpa menghapus aplikasi/data lama.
2. Sebelum mematikan laptop, periksa pengaturan gateway memakai alamat
   `https://zikra-ai.vercel.app` dan akses instalasi yang sudah tersimpan. Jangan
   mengubah key provider atau menyalin token ke screenshot/catatan publik.
3. Buka chat baru untuk uji. Matikan pengiriman konteks pribadi/riwayat bila aktif.
   Gunakan mode online; bila memakai Otomatis, hasil akhirnya wajib berlabel Online,
   bukan panduan offline. Belum perlu mengirim pesan pada tahap persiapan ini.
4. Cabut USB dan matikan laptop sepenuhnya. Setelah laptop benar-benar mati,
   kirim sekali dari HP, dengan persetujuan pengiriman yang ditampilkan aplikasi:

   > Uji koneksi Zikra. Sebutkan satu cara merapikan meja belajar dalam satu kalimat.

5. Catat waktu WIB, versi APK, jenis jaringan, bahwa laptop sudah mati sebelum
   Kirim, label hasil dan apakah balasan baru diterima. Screenshot chat sintetis
   boleh disimpan sebagai bukti; hindari profil/chat asli dan pengaturan akses.
6. Setelah laptop dinyalakan kembali, hasil bisa dicatat pada laporan proyek.
   Lulus hanya jika pesan baru benar-benar dijawab online ketika laptop mati.
   Balasan lama/cache, panduan offline, health200 saja, timeout atau quota/error
   tidak memenuhi syarat. Jangan mengulang berkali-kali jika gagal; catat error.

Pengiriman menggunakan kuota AI biasa, tanpa lampiran atau data pribadi. Ini
hanya menutup gerbang kemandirian hosting C02 setelah bukti ditinjau. Mikrofon
C06, kamera/picker C07, konteks C04 dan rilis publik mempunyai uji terpisah.

Catatan hasil, diisi hanya sesudah uji:

| Data | Hasil |
| --- | --- |
| Tanggal/jam WIB | Belum diuji |
| Versi APK / code | Belum dicatat |
| Jaringan HP | Belum dicatat |
| Laptop mati sebelum Kirim | Belum dibuktikan |
| Balasan baru / label Online | Belum dibuktikan |
| Kesalahan / bukti | Belum tersedia |
