# Gerbang izin audio D02/D02a

[Draf permintaan](request-template.md) disiapkan secara lokal, **belum dikirim**.
Tidak ada alamat penerima yang diasumsikan. Pengiriman memerlukan instruksi
pengguna dan penerima yang diverifikasi; tidak ada pesan pihak ketiga dikirim
pada checkpoint ini.

Kedua rekaman aktif cocok byte/hash dengan unduhan penerbit pada pemeriksaan
sebelumnya; lihat [bukti sumber](../../android/validation/adhan-source-current-2026-11-11/README.md).
Tawaran unduhan gratis bukan izin memasukkan rekaman ke APK/AAB. Penerbit laman
belum tentu pemilik hak rekaman. Kesesuaian lafaz penuh juga belum dinyatakan lulus.

Simpan korespondensi asli dan bukti kewenangan di `.local/audio-permissions/`.
Catat metadata izin yang boleh dipublikasikan setelah diterima: pemberi izin,
kewenangan, hash dua rekaman, cakupan, masa berlaku, atribusi dan pembatasan.
Jangan menyalin alamat, lampiran pribadi atau data kontak ke Git tanpa kebutuhan
dan persetujuan. Jika izin tidak tersedia, pilih rekaman dengan izin eksplisit
setelah pengguna menyetujui penggantian. Audio aktif tidak diubah di sini.

- [ ] Penerima/pemilik hak atau kewenangan terverifikasi.
- [ ] Izin distribusi APK/AAB dan pemutaran lokal diterima tertulis.
- [ ] Cakupan komersial/nonkomersial, wilayah, durasi dan atribusi jelas.
- [ ] Identitas pembaca dan lafaz rekaman diperiksa.
- [ ] Bukti izin disimpan privat; metadata publik ditinjau.
