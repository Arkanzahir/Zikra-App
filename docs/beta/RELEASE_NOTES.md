## Instal dan pembaruan

1. Unduh hanya melalui kanal resmi yang nanti diumumkan. Cocokkan versi/ukuran
   dan SHA-256 yang menyertai paket.
2. Buka APK melalui Files dan izinkan pemasangan dari aplikasi tersebut jika
   Android meminta. Jangan menonaktifkan perlindungan HP secara menyeluruh.
3. Pembaruan memerlukan application ID dan signer yang sesuai. Jika Android
   menolak, jangan hapus aplikasi lama; laporkan versi/error lebih dahulu agar
   data lokal tidak hilang. Instalasi debug yang sudah ada perlu rencana khusus.
