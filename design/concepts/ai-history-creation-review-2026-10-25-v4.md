# Zikra AI — riwayat dan kreasi, konsep v4

25 Oktober 2026. Permintaan pengguna: riwayat seperti aplikasi AI percakapan, kreasi gambar, pola interaksi familiar tetapi identitas berbeda. [Preview](ai-history-creation-review-2026-10-25-v4.png) baru **rancangan target**, belum implementasi, belum hasil API nyata dan belum disetujui secara khusus. Tidak memakai merek/logo GPT/Gemini atau mengklaim kemampuan yang sama.

Keadaan saat ini: satu riwayat lokal bounded pada preferences, bukan daftar percakapan terpisah. Target C08: daftar chat, cari, buat baru, judul/ubah/hapus dengan konfirmasi, pulih setelah aplikasi ditutup, migrasikan riwayat lama tanpa hilang; data tetap lokal dan pengiriman konteks tetap atas pilihan pengguna. Jangan mengirim seluruh daftar chat sebagai konteks otomatis.

Target C09: generasi gambar online melalui layanan/model yang benar-benar menghasilkan gambar; API akses, hak penggunaan, kuota/biaya dan respons aktual perlu dibuktikan sebelum tombol dinyalakan. Metadata tag “Image Generation” pada katalog model tidak membuktikan adanya endpoint rendering gambar: hasil pencarian resmi juga berisi model teks untuk penyusunan prompt. Backend sekarang hanya content string dan completion teks; belum ada rute gambar. Tidak membeli layanan, mengganti key privat atau mengaku tool image_gen sesi ini otomatis menjadi API aplikasi. Preview taman adalah contoh visual generatif pada mockup, bukan output aplikasi.

Home tidak perlu menunggu C08/C09 atau seluruh C: implementasi Home yang disetujui sudah dimulai pada putaran ini, sedangkan AI tetap memerlukan penanganan terpisah sesuai checklist.

Dibuat memakai built-in image_gen. Prompt persis:
