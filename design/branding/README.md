# Logo utama Zikra

Desain utama dipertahankan: bulan sabit dan buku hijau emerald dengan spark emas. File ini dipulihkan dari desain logo utama yang sebelumnya ada di repositori; tidak ada perubahan piksel.

[![Logo utama Zikra](zikra-logo-primary.jpg)](zikra-logo-primary.jpg)

- Referensi desain utama: [`zikra-logo-primary.jpg`](zikra-logo-primary.jpg).
- Ikon yang saat ini dipakai aplikasi: [`app_icon.png`](../../android/app/src/main/res/drawable/app_icon.png), versi putih pada latar Pine, dirujuk oleh manifest Android.
- Pertahankan identitas bulan, buku dan spark ketika menyempurnakan desain. Palet aplikasi mengikuti README utama; latar navy gambar referensi tidak mengubah tema aplikasi secara otomatis.

Folder branding terpisah dari [referensi tampilan pengguna](../README.md). Mockup halaman, alternatif logo dan prompt desain lama yang sudah dihapus tidak dikembalikan.
